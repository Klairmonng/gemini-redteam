Applied AI · prompt injection study on Gemini

Did the model leak the code?

A support bot is told to keep one access code secret. Attack prompts try to get it out, every answer is recorded, and a panel of judges grades how far the model slipped, from 0 (kept the secret) to 3 (full leak). Build the pipeline from blocks below and run it on the recorded answers.

  1. AttackOne prompt from the test set, such as a regex search or a story.
  2. TargetThe Gemini model that receives it, with the instruction above.
  3. ResponseThe visible answer, the code the model ran, and what that code printed.
  4. JudgesCanary rules plus LLM judges from other model families.
  5. VerdictA level from 0 to 3, and a flag when the judges disagree.

      Judge quality over time
      
        
      Do the judges drift?
      
        
      Each grade a judge gives is compared with a reference: the hand label, or the rule check when there is none. The difference is watched in the order the grades were made. A judge that turns stricter or more lenient, for example after a silent model update, pushes the EWMA line out of its band or a CUSUM line over its threshold.
      
      
      
      
      
      
      
      
      
        
      
          
      EWMA of the grade difference
      
          
      
          
      The line is a running average that gives the newest grade weight λ. The shaded band is the control limit; a point outside it is an alarm. Above 0 means stricter than the reference, below 0 more lenient.
      
        
      
        
      
          
      CUSUM in both directions
      
          
      
          
      
          
      Each line adds up how far the grades sit beyond the slack k in one direction and resets at 0. Crossing the threshold h is an alarm. CUSUM catches small steady shifts that EWMA can miss.
      
        
      
      
      
      
      
        Table view of every grade
        
      
      
      
      
      An alarm says the judge's relation to the reference changed. A new kind of response can cause that as well as a changed judge, so check the responses around the alarm. To test the judge alone, grade the same hand-labelled set again on later days and pick "Hand labels only".
      
    
      
  
      

  
      
    
      
      
      
        
      Algorithmic Programming
      
        
      Sort and search the results
      
        
      The recorded answers go into three data structures written for this project: a doubly linked list, a hash map and a binary search tree. Sort them with quick, merge or insertion sort and search them four ways. Each step shows how long it took, and each result is checked against Python's own sorted() or a scan of every record.
